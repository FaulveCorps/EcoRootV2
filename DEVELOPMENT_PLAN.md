# EcoRoot — Development Plan & Timeline

This plan turns the long‑term context into a concrete delivery timeline. It is the baseline reference for all future “continue” requests and time estimates.

## Assumptions
- Small team (1–3 people)
- Content sourced or drafted in parallel with development
- .NET MAUI (MVVM) with SQLite for local storage
- Target platforms: Android, iOS, Windows, macOS

## Phase Overview (Estimated)
- **Phase 0 — Setup & Discovery:** 1 week
- **Phase 1 — UX + Content Blueprint:** 2 weeks
- **Phase 2 — MVP Build:** 4 weeks
- **Phase 3 — v1 Expansion:** 4 weeks
- **Phase 4 — v2+ Enhancements:** 6+ weeks (iterative)

Total to MVP: **7 weeks**
Total to v1: **11 weeks**

## Phase 0 — Setup & Discovery (Week 1)
**Goals**
- Confirm learning outcomes and content pillars
- Establish UI style guide and app architecture
- Create project scaffolding and CI baseline

**Deliverables**
- Project repo with MAUI shell, MVVM base, SQLite setup
- UI style tokens (colors, typography, spacing)
- Initial content outline (lesson titles & summaries)

## Phase 1 — UX + Content Blueprint (Weeks 2–3)
**Goals**
- Build the information architecture and navigation
- Prototype lesson, quiz, and glossary flows
- Draft core lesson content for MVP

**Deliverables**
- Clickable UX prototype (screens & flows)
- Content blueprint for MVP modules
- Finalized data model for lessons/quizzes

## Phase 2 — MVP Build (Weeks 4–7)
**Goals**
- Implement Foundations, Sources, Impacts modules
- Add quizzes, glossary, and progress tracking
- Ensure offline access and basic analytics (local)

**Deliverables**
- MVP app on mobile + desktop
- Lesson reader, quiz engine, glossary
- Local progress tracking and badges (basic)

## Phase 3 — v1 Expansion (Weeks 8–11)
**Goals**
- Add Solutions module and teacher resources
- Improve achievements and navigation
- Polish UI and accessibility

**Deliverables**
- v1 release with Solutions content
- Enhanced progress dashboards
- Accessibility pass and UI refinements

## Phase 4 — v2+ Enhancements (Weeks 12+)
**Goals**
- Add localization support
- Introduce richer interactive activities
- Optional cloud sync (if needed)

**Deliverables**
- Multi‑language support
- Interactive simulations or scenario labs
- Optional sync module with consent flow

## Key Milestones
- **M1:** Project scaffolding + data model (End of Week 1)
- **M2:** UX prototype + content blueprint (End of Week 3)
- **M3:** MVP release (End of Week 7)
- **M4:** v1 release (End of Week 11)

## Dependencies & Risks
- Content accuracy and availability of local case studies
- Device performance on low‑end hardware
- Schedule impact from cross‑platform testing cycles

## How to Use This Plan
- When you say **“continue”**, I’ll proceed to the next actionable tasks in this plan.
- All timeframe estimates will reference the phase and week count above.

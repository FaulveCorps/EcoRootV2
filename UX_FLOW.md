# EcoRoot — UX Flow (Phase 1)

This document captures the core navigation and screen flow for the MVP.

## Primary Navigation
- **Home** → entry point to start learning and see progress
- **Modules** → list of learning pillars
- **Glossary** → search and browse terms
- **Progress** → badges and completion overview
- **Teacher Resources** → classroom prompts and activities (v1)

## Screen Flow
### 1) Home
- Hero message + quick action: “Start Foundations”
- Today’s Focus card
- Learning pillars list
- Shortcut to Glossary
- Teacher resources shortcut (v1)

### 2) Modules (Pillars)
- Foundations
- Pollution Sources
- Impacts
- Solutions (v1)
- Local Context (v2+)

### 3) Module Detail
- Module overview
- Lesson list (3–5 lessons)
- Progress indicator

### 4) Lesson Reader
- Lesson content in short sections (5–8 min)
- Inline glossary highlights
- “Check Understanding” CTA

### 5) Quiz
- 3–5 questions per lesson
- Immediate feedback (correct/incorrect)
- Summary + next lesson CTA

### 6) Glossary
- Search bar
- Term list
- Term detail sheet

### 7) Progress
- Module completion rates
- Badges earned
- “Keep Going” recommendations

### 8) Teacher Resources (v1)
- Discussion prompts and activity ideas

## Accessibility Notes
- Large tap targets
- High contrast by default
- Content readability (line height + spacing)

# EcoRoot — Test Plan (MVP)

This plan outlines minimal tests needed before the MVP milestone.

## 1) Smoke Tests
- Launch on Windows desktop
- Navigate: Home → Modules → Lesson → Quiz → Progress
- Confirm progress updates after quiz completion

## 2) Data Persistence
- Complete a quiz, close app, relaunch
- Verify lesson marked completed and quiz attempt listed

## 3) Offline Content
- Run without internet
- Confirm modules and lessons load from cached content

## 4) Accessibility Basics
- Headings read in screen reader order
- Buttons and labels are discoverable

## 5) Regression Checks
- Ensure navigation routes still resolve (Modules → Lesson → Quiz)
- Confirm glossary still accessible
